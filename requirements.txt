# Зафиксированный набор для Docker-образа (datadrivers-wine-recognizer).
#
# Сгенерировано кросс-резолвом под python 3.11 / linux-arm64 и проверено фактическим
# запуском (импорты, загрузка моделей, реальный вызов). Зафиксированы ВСЕ пакеты,
# включая транзитивные: раньше здесь было 12 записей без якорей, из-за чего версии
# плава��и от сборки к сборке.
#
# ВАЖНО 1: python 3.11, не 3.12 — torch публикует wheels только до cp311 (sdist нет).
# ВАЖНО 2: torch 2.14.0, а НЕ 2.1.0. В 2.1.0 на aarch64 linux падает с Segmentation
#   fault базовый nn.LSTM (oneDNN-rnn, расширяется conv2d). Из-за этого easyocr падал
#   при первом же реальном вызове readtext. На macOS этот баг не воспроизводится.
# ВАЖНО 3: CUDA-зависимости (nvidia-*, cuda-*, triton) здесь НЕ перечислены намеренно.
#   torch тянет их по маркеру platform_system == "Linux", поэтому внутри образа (Linux)
#   pip доставит их сам (~2.5 ГБ, осознанно оставлены ради гарантий разрешения
#   зависимостей), а на macOS они не ставятся, что позволяет проверять импорты локально.
